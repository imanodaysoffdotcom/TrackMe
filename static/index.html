QOSF · QUIC OS Fingerprint

QOSF is a readable, QUIC-only passive fingerprint, computed alongside your QUIC JA4/SPHBI. Your QUIC transport parameters identify the QUIC library (segments B/C/D); the OS signal is the kernel TTL on the UDP datagram (segment A), read by the packet tap. Format q<ttl><ip><ecn><df><flow>_<stack><ver><order><grease><scid>_<tp-set>_<tp-values>.

Kernel space vs. user space

QUIC runs in user space, so almost the whole fingerprint is written by the QUIC library — only the IP/UDP header (segment A) is written by the OS kernel. That is exactly why the OS signal has to come from the kernel TTL, not from anything QUIC sends.

Every field · observed vs derived vs absent

Legend — observed = read directly from your packets; derived = inferred or classified (initial TTL rounded up; an unverified stack → xx); absent (—) = the client did not send it (never a fabricated RFC default). QOSF is valid only when this server is the first-hop QUIC terminator (TrackMe is, via quic-go).

The contradiction stack

Defenders win through cross-layer correlation. Faking the top of the stack (the User-Agent) is cheap — but every faked signal has to stay consistent with the harder-to-fake signals beneath it. Below is your live request, testifying for or against itself: the actual value we extracted at each layer, and a rule verdict on whether it agrees with the claim.

A contradiction means a lower layer — which is expensive or impossible to fake — disagrees with the User-Agent on top. These are heuristics: a privacy tool, proxy, or VPN can also cause a mismatch, so treat a contradiction as a strong signal, not proof.

SPHBI image matrix — field map

How the 18 selected TCP/IP header bytes (144 bits) are arranged into the 12×12 SPHBI binary image, and which header signal drives each pixel/region. The bits fill the grid row-major (bit i → pixel x=i%12, y=i/12), each byte most-significant-bit first. Cool colours = IP/IPv6 base header; warm colours = TCP header. Hover any cell for its field, byte and bit range. Two layouts below — IPv4 and IPv6 (the IPv6 base header carries fewer bytes, so the TCP MSS option backfills the image to 144 bits).
